How search works

Type the name of any software or hardware, like Chrome, Cisco or router. Big Frog checks every headline, summary and tag in every feed and shows only the feeds that have matching stories.

Open a feed box to see its stories, with matches highlighted. Inside a feed you can sort by date (newest first) or by severity. Search updates as you type. It only searches the data already loaded on this page, not the whole internet.

Big Frog also sticks tags on stories: pink for topics (ransomware, zero-day, phishing…), lavender for vendors and products, and mint for the source's own labels. Click a tag to search for it.
